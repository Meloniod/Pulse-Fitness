# Client Demo Checklist

Before the meeting:
- [ ] Run the local app and confirm the dashboard loads.
- [ ] Reset to fictional sample data.
- [ ] Prepare one fictional client to add live.
- [ ] Prepare one programme, session and nutrition entry to demonstrate.
- [ ] Show payment status tracking without implying payment processing.
- [ ] Open the companion workbook or generate it from the script.
- [ ] Keep the QA checklist and known limitations available.

During the meeting:
- [ ] Ask how the trainer currently manages each workflow.
- [ ] Confirm which features are genuinely valuable.
- [ ] Capture required roles, reports, integrations and client-facing access.
- [ ] Avoid entering real personal or health information into the demo.
- [ ] Confirm that pricing and production scope require validation.

After the meeting:
- [ ] Summarise feedback and prioritise requirements.
- [ ] Confirm the data model and privacy requirements.
- [ ] Prepare a scoped implementation proposal.
