# PULSE Demo — User Guide

## Start
1. Install Node.js 20 or later.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.

## Dashboard
Review active clients, sessions for the demo date, received payments and outstanding balances.

## Clients
Use Add client to capture a name, email, fitness goal and status. Use search to find a record. Archive inactive records rather than treating them as active.

## Programmes
Create a programme, enter its focus and exercises, and optionally assign it to a client.

## Schedule
Create a session with a client, date, time and session type. Mark a scheduled session completed after delivery.

## Nutrition
Log client-reported meals, calories, protein and water intake. This is a recording tool only; it does not provide dietary or medical advice.

## Payments
Record a payment amount and date. Use Paid, Pending or Overdue status. The demo records status only and does not collect or process money.

## Reset
Use Reset demo data to restore the original fictional sample records. This discards changes in the current browser.

## Important
All demo changes are stored in the current browser only. They do not sync between devices. Never enter real client or sensitive information.
