# PULSE Companion Tracker

The companion workbook is designed for Excel and Google Sheets import. The tracker mirrors the demo's client, programme, session, progress, nutrition and payment workflows.

## Workbook tabs
1. START HERE — purpose and setup
2. USER GUIDE — instructions for the trainer
3. DASHBOARD — summary metrics
4. CLIENT REGISTER — client profile and status
5. EXERCISE LIBRARY — exercise reference
6. PROGRAMME PLANNER — programme structure and assignment
7. SESSION LOG — scheduled and completed sessions
8. PROGRESS TRACKER — consent-based progress notes
9. NUTRITION LOG — client-reported food and hydration
10. PAYMENT REGISTER — manual payment status
11. SETTINGS — dropdown values and configuration

Upload the XLSX workbook to Google Drive and choose Open with Google Sheets. Review formulas, formatting and dropdown validation after import. Use fictional sample data only. Nutrition and progress records are not medical advice.
